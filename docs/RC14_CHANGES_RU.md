# DiamondCraft 1.0 RC14 — Google Play Release Candidate

## Что изменено

- `versionCode` = 190, `versionName` = `1.0-rc14`.
- Debug APK остаётся полностью разблокированным Pro для локального тестирования.
- Release-сборка больше не получает Pro автоматически: право Pro берётся из Google Play Billing.
- Добавлен `PlayBillingController` для одноразовой покупки Pro.
- Product ID для Play Console зафиксирован: `diamondcraft_pro_lifetime`.
- Добавлены восстановление покупки и повторная проверка права Pro при запуске.
- Покупка выдаёт Pro только при состоянии `PURCHASED`; pending-платёж не разблокирует функции.
- Не подтверждённая покупка подтверждается через Billing Library.
- В GitHub Actions добавлена подготовка подписанного Google Play AAB через repository secrets.
- Без upload-key workflow по-прежнему собирает тестовый APK и неподписанный release AAB.

## Важно перед реальной продажей

1. Создать приложение DiamondCraft в Play Console.
2. Создать одноразовый товар с точным ID `diamondcraft_pro_lifetime`.
3. Загрузить релиз сначала во внутреннее/закрытое тестирование.
4. Создать отдельный upload key и добавить четыре GitHub Secrets по инструкции.
5. Проверить покупку, отмену, pending-покупку и восстановление покупки тестовым аккаунтом.
6. Только после этого отправлять production-релиз.

## Модель доступа

### Free
- до 100 страз по ширине;
- до 60 цветов;
- создание и сохранение проектов;
- отметка прогресса.

### Pro — одноразовая покупка
- до 200 страз по ширине;
- до 120 цветов;
- PNG/PDF/CSV;
- импорт/экспорт `.diamondcraft`;
- расширенные режимы обработки.

RC14 не меняет генератор схем, формат сохранённых проектов, Undo/Redo и расчёт расходников.
