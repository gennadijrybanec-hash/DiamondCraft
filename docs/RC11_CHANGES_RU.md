# DiamondCraft 1.0 RC11

Исправления по итогам приёмочного теста RC10:

- один палец на схеме оставлен для вертикальной прокрутки страницы;
- два пальца управляют масштабом и перемещением схемы;
- схема центрируется в рабочей области;
- отрисовываются только видимые клетки для повышения плавности;
- добавлены Назад / Вперёд для отметок прогресса (до 50 шагов);
- при первом сохранении предлагается имя проекта;
- добавлено переименование сохранённых проектов;
- добавлено пояснение о влиянии круглых/квадратных страз на физический размер;
- версия: 1.0-rc11, versionCode 160.
