# Политика конфиденциальности DiamondCraft — черновик

DiamondCraft предназначен для создания схем алмазной мозаики из изображений пользователя.

## Обработка изображений
Выбранные пользователем фотографии обрабатываются локально на устройстве для создания схемы.

## Проекты
Сохранённые проекты хранятся локально на устройстве, пока пользователь сам их не экспортирует или не удалит.

## Платежи
После подключения DiamondCraft Pro обработка покупок будет выполняться Google Play. Приложение не будет получать данные банковской карты пользователя.

## Сторонние каталоги
Если в будущем будет подключён каталог товаров/магазинов, политика будет обновлена до публикации соответствующей функции.

## Контакты
Перед публикацией сюда необходимо добавить официальный адрес поддержки разработчика.
