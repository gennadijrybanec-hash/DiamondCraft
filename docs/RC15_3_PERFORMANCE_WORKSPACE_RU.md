# DiamondCraft 1.0 RC15.3 — Performance Workspace

Контрольная доработка поверх RC15.2 / versionCode 193.

## Что изменено

- versionCode: 194
- versionName: 1.0-rc15.3-performance-workspace
- Выбор фотографии больше не запускает тяжёлое построение схемы автоматически.
- После выбора фото пользователь сначала видит настройки и отдельную кнопку «Создать схему».
- Кнопка «Создать схему» закреплена внизу экрана и остаётся доступной на компактных телефонах, включая Xiaomi Mi 8.
- Построение схемы вынесено с UI-потока; во время расчёта показывается блокирующий индикатор «Создаём схему…».
- Большие исходные фотографии декодируются с ограничением размера, чтобы снизить расход памяти.
- После создания приложение автоматически открывает отдельный рабочий экран проекта.
- Рабочий экран больше не находится внутри длинной общей прокрутки настроек.
- Схема занимает центральную область экрана; доступны масштаб, панорамирование двумя пальцами, отметка страз, Undo/Redo и «По размеру».
- Добавлен быстрый режим отрисовки при малом масштабе: вся большая схема рисуется одним bitmap вместо десятков тысяч кругов.
- При крупном масштабе рисуются только реально видимые стразы.
- Расчёт статистики и материалов кэшируется через remember.
- «Изменить настройки» возвращает к исходной фотографии без потери проекта; повторное создание сохраняет ID/имя текущего проекта.
- Материалы, палитра, сохранение, список покупок и экспорт остаются доступны с рабочего экрана.
- Free/Pro и Google Play Billing не менялись.

## Релизная тактика

Эту ветку/архив не загружать в текущий закрытый тест до окончания действующего тестового периода. Сначала сохранить как контрольный исходник и позже собрать/проверить отдельной сборкой.
