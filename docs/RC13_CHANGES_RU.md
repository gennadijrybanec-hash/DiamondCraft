# DiamondCraft 1.0 RC13

## Что изменено

- Более мягкая графитово-фиолетовая тема вместо почти чёрного фона RC12.
- Снижена визуальная жёсткость белого текста и ярких акцентов для длительной работы.
- Фирменный стиль DiamondCraft и новая иконка сохранены.
- Версия поднята до 1.0-rc13 (versionCode 180).
- Google Play Billing Library 9.1.0 сохранена как база коммерческого режима.
- GitHub Actions теперь дополнительно собирает Release Android App Bundle (AAB) для подготовки Google Play.
- Проверенное ядро RC12: генерация, проекты, Undo/Redo, экспорт и расчёты не изменялись.

## Важно

RC13 всё ещё использует тестовый Pro-флаг, чтобы sideload-сборка не заблокировала функции до создания товара Pro в Play Console. Перед production-релизом тестовый флаг должен быть заменён подтверждённым entitlement Google Play.
