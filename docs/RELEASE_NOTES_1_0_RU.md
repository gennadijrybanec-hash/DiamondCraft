# DiamondCraft 1.0 — черновик примечаний к выпуску

Первая версия DiamondCraft.

- Создание схем алмазной мозаики из фотографий.
- Настройка размера и количества цветов.
- Профили обработки изображения.
- Сравнение оригинала и схемы.
- Масштабирование и отслеживание прогресса.
- Сохранение, импорт и экспорт проектов.
- PNG, PDF и CSV.
- Расчёт количества страз и размеров основы.
- Список покупок материалов.
