# DiamondCraft — финальный тест на телефоне

Проверить перед публикацией:

1. Обновление RC9 → RC10 без удаления приложения.
2. Иконка DiamondCraft на рабочем столе.
3. Создание схемы из фотографии.
4. Режимы: Авто / Портрет / Предмет / Пейзаж.
5. Цветопередача: Естественный / Яркий / Насыщенный.
6. Переключение Оригинал / Схема.
7. Масштабирование и перемещение только внутри окна.
8. Отметка отдельных страз и точный процент прогресса.
9. Снять все отметки.
10. Сохранить проект, закрыть приложение, открыть и восстановить.
11. Экспорт `.diamondcraft`, Новый проект, импорт `.diamondcraft`.
12. Удаление сохранённого проекта с подтверждением.
13. PNG, PDF, CSV.
14. Список покупок и копирование.
15. Квадратные / круглые стразы.
16. Запас страз и расчёт основы.
17. Экран PRO.
18. Экран «О приложении».
19. Проверить работу после поворота экрана.
20. Проверить отсутствие вылетов после нескольких проектов подряд.

Если все пункты проходят, функциональную часть 1.0 фиксируем и переходим к Play Console.
