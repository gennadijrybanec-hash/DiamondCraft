# DiamondCraft 0.3 — first Android prototype

Первое запускаемое Android-приложение на Craft Engine.

Уже работает в коде:
- выбор фотографии через Android picker;
- фото -> сетка алмазной мозаики через общий `:core`;
- настройка ширины 20–100 страз;
- палитра и подсчёт страз по цветам;
- интерактивная схема;
- pinch zoom / pan;
- отметка установленных страз и общий прогресс;
- отдельный applicationId `com.craftengine.diamondcraft`;
- GitHub Actions для APK.

Это технический prototype 0.3, не коммерческий релиз. Следом: сохранение проектов, импорт/экспорт, реальная палитра страз, UI polish и Free/Pro.
